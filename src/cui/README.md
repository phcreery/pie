# CUI

Vendored amalgamation of [CUI](https://github.com/yappologistic/CUI), MIT.

Generated by `tools/amalgamate.py` in the upstream repository, then patched so
pie only builds what it uses:

- `cui.c` wraps the software and OpenGL renderer blocks in
  `#ifndef CUI_NO_OTHER_RENDERERS`; pie draws CUI through its own sokol-gfx
  backend (`src/gui/cui_sokol.zig`), and the software renderer needs pthreads
  (not available on Windows).
- The build compiles with `CUI_NO_APP` (sokol_app owns the window) and
  `CUI_NO_OTHER_RENDERERS`.

Everything else is upstream. Re-apply the two guard lines when updating.
